# Prime Readiness Checklist — CMMC Level 2 Subcontractors
_To be pasted into Google Docs and shared as a gated asset._

## Cover Summary
- Audience: GovCon subcontractors (10–150 employees) preparing for CMMC Level 2.
- Promise: Know exactly what primes, DFARS auditors, and Supplier Performance Risk Reports expect before they ask.

## Sections

### 1. Identity & Documentation
- [ ] System Security Plan (SSP) last updated date (mm/dd/yyyy).
- [ ] Assigned owner for SSP upkeep.
- [ ] Plan of Action & Milestones (POA&M) with open items < 120 days old.
- [ ] Written evidence of DFARS 252.204-7012 clause acceptance.

### 2. SPRS Scorecard Snapshot
- [ ] Current SPRS score recorded (include screenshot or PDF export).
- [ ] Breakdown of top 3 controls lowering the score, with remediation owner.
- [ ] Evidence of self-attestation submission date.
- [ ] Calendar block for quarterly score refresh.

### 3. Access & Credential Hygiene
- [ ] Multi-factor authentication enforced for all users with CUI access.
- [ ] Quarterly access review log (template link placeholder `{{access_review_template}}`).
- [ ] Guest/vendor accounts inventoried and disabled when not in use.
- [ ] Admin credential storage documented (vault, rotation policy).

### 4. Logging & Monitoring
- [ ] Centralized log collection (tool + retention setting noted).
- [ ] Alert thresholds for unauthorized login attempts.
- [ ] Evidence of weekly log review (who, when, outcome).
- [ ] Incident escalation runbook reference.

### 5. Incident Response Readiness
- [ ] Named incident commander + backup.
- [ ] Tabletop exercise completed in last 6 months.
- [ ] Communications tree for primes / DoD reporting (with contact info).
- [ ] After-action template prepared.

### 6. Supplier & Flow-Down Controls
- [ ] List of subcontractors handling CUI.
- [ ] Contracts updated with CMMC Level 2 requirements.
- [ ] Evidence of supplier SPRS checks or equivalent diligence.
- [ ] Remediation steps for suppliers below threshold.

### 7. Workforce Training & Awareness
- [ ] Annual security training completion log.
- [ ] Targeted training for privileged users.
- [ ] Phishing simulation score tracked.
- [ ] Policy acknowledgement forms stored centrally.

### 8. Evidence Locker
- [ ] Designated secure folder/portal for evidence uploads.
- [ ] Naming convention documented.
- [ ] Access limited to compliance owners + auditors.
- [ ] 48-hour export process documented.

## Bonus: Prime Conversation Script
1. Lead with your latest SPRS score and update date.
2. Highlight any compensating controls for objectives <100% implemented.
3. Offer read-only view of your evidence locker for 72 hours.
4. Ask the prime which control families they scrutinize first — log the answer.
