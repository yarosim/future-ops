# skill: cold-outreach-generator

## Goal
Generate multi-channel cold outreach using niche-specific language that converts strangers into conversations.

## Inputs
- niche (from niche-research)
- ICP (ideal customer profile)
- offer (the specific recurring service)
- channel (email, LinkedIn, SMS, cold call, DM)

## Rules
- Use the niche's own language (from language_dictionary.md)
- One pain point at a time
- One CTA per message
- No hype
- No fake personalization
- Short, direct, human

## Output
- 5 email variants (different angles on the same pain)
- 5 LinkedIn variants (connection request + follow-up)
- 3 SMS variants (ultra-short, one CTA)
- 3 call openers (first 15 seconds of a cold call)
- 5 follow-up messages (for non-responders, spaced across channels)

## Quality Gate
Every variant must:
- Reference a real pain point from niche-research
- Use language the prospect actually uses
- Have exactly one clear next step
- Be sendable without edits
