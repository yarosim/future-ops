# skill: client-onboarding-workflow

## Goal
Turn a signed client into an organized delivery workflow with zero re-asking and zero dropped balls.

## Inputs
- service sold (what was closed)
- client details (from CRM / discovery notes)

## Output
- **kickoff_agenda.md** — what to cover in the first call
- **intake_checklist.md** — everything needed from the client
- **access_request_list.md** — logins, permissions, assets required
- **content_assets_needed.md** — copy, images, branding, etc.
- **automations_to_configure.md** — what gets set up and where
- **timeline.md** — week-by-week delivery milestones
- **milestones.md** — checkpoints with success criteria
- **internal_owners.md** — who does what internally
- **risk_flags.md** — what could go wrong and how to prevent it

## Rule
The handoff package must be complete enough that Fulfillment can start without asking a single clarifying question.
