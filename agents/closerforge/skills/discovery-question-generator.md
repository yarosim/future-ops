# skill: discovery-question-generator

## Goal
Generate niche-specific discovery questions that uncover real problems, qualify budget, and surface urgency.

## Inputs
- niche (from niche-research output)
- offer type (e.g., voice AI, reputation management, automation)

## Process
1. Pull pain points and language from niche-research output
2. Generate open-ended questions that surface the pain
3. Generate follow-up probes that deepen the conversation
4. Map qualification signals (budget, authority, need, timeline)
5. Prepare objection responses based on niche fears

## Output
- discovery_questions.md — 10-15 open-ended questions per niche
- follow_up_probes.md — 5-8 deeper probes per question category
- qualification_signals.md — what to listen for that indicates a real buyer
- objections_to_expect.md — top 5-7 objections with pre-built responses

## Rule
Every sales call gets a discovery pack before it happens. No winging it.
