# CloserForge Skills Pack

Skills are installed once and reused across niches. Each skill has defined inputs, outputs, and can be chained into workflows.

---

## Core Skills (Research + Sales Foundation)

### 1. niche-research
- **Inputs:** industry, geography, customer type
- **Outputs:** market size, pain points, language dictionary, forums, events, fears, gaps, buying triggers
- **Purpose:** Ground every outreach and offer in actual market intelligence.

### 2. discovery-question-generator
- **Inputs:** niche, offer type
- **Outputs:** call questions, follow-up probes, qualification signals, objections to listen for
- **Purpose:** Run better sales calls with niche-specific questions.

### 3. cold-outreach-generator
- **Inputs:** niche, ICP, offer, channel
- **Outputs:** email, LinkedIn, SMS, voicemail, DM variants
- **Purpose:** Multi-channel outreach using niche language.

### 4. client-onboarding-workflow
- **Inputs:** service sold
- **Outputs:** kickoff checklist, data-request list, timeline, automations, internal task map
- **Purpose:** Smooth handoff from close to delivery.

### 5. 10x-vision
- **Inputs:** niche + offer + current results
- **Outputs:** blind spots, upsells, expansion angles, premium packaging
- **Purpose:** Find what the client (and you) are missing.

## Revenue Skills (Offer → Close)

### 6. offer-designer
Design recurring service offers with clear scope, deliverables, and value prop.

### 7. pricing-packager
Create tiered pricing (starter/growth/enterprise) with margin analysis.

### 8. objection-handler
Generate objection responses mapped to niche-specific fears and concerns.

### 9. proposal-writer
Produce client-ready proposals grounded in discovery and niche research.

### 10. roi-calculator
Build ROI projections clients can understand and trust.

### 11. followup-sequencer
Design multi-touch follow-up sequences with timing and escalation logic.

### 12. lead-qualifier
Score leads on fit, intent, budget, and timeline. Route or disqualify.

### 13. case-study-builder
Turn completed work into sellable case studies and social proof.

### 14. sales-call-prep
Pre-call package: prospect research, talking points, objection prep, ask sequence.

### 15. close-plan-generator
Map the path from current stage to signed deal with specific next steps.
