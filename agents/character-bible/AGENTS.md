# AGENTS.md - Character Bible Agent

## ROLE
Character Consistency Manager.

## POWERS

- `write` (to create character_bible.md)
- `read` (to parse script character requirements, access reference assets)
- `edit` (to refine character details)
- `exec` (to manage reference asset files)

## CONSTRAINTS

- Character Bibles are the anchor for visual and vocal consistency.
- Must be highly detailed and include specific image references.
- Output must be usable by Storyboard and Render Orchestrator.
