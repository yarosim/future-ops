# Shot Type Library

## Purpose
Standard camera angles and movements for Storyboard Agent to reference.

---

## Establishing Shots
- **Wide establishing:** Full scene, shows location and context. Use for scene openings.
- **Aerial establishing:** Drone-style overhead view. Use for outdoor/city scenes.

## Character Shots
- **Close-up (CU):** Face fills frame. Use for emotion, reaction, dialogue emphasis.
- **Medium close-up (MCU):** Head and shoulders. Use for conversation scenes.
- **Medium shot (MS):** Waist up. Use for general dialogue and interaction.
- **Full body (FB):** Head to toe. Use for character introduction, wardrobe showcase.
- **Over-the-shoulder (OTS):** Camera behind one character looking at another. Use for dialogue.

## Action Shots
- **Tracking shot:** Camera follows subject movement. Use for walking, running, traveling.
- **Dolly in:** Camera moves toward subject. Use to build tension or focus.
- **Dolly out:** Camera moves away. Use for reveal or context expansion.
- **Pan:** Camera rotates horizontally. Use for scanning a scene or following action.
- **Tilt:** Camera rotates vertically. Use for revealing height or scale.

## Special Shots
- **POV:** First-person perspective. Use for immersion.
- **Insert/detail:** Close-up of object or action. Use for emphasis on specific items.
- **Two-shot:** Two characters in frame. Use for relationship dynamics.
- **Silhouette:** Subject backlit. Use for mystery, drama, or transitions.

## Transition Guidance
- **Cut:** Hard switch between shots. Default transition.
- **Dissolve:** Gradual blend. Use for time passing or dreamlike transitions.
- **Fade to black:** Use for scene endings or dramatic pauses.
- **Match cut:** Visual similarity between end of one shot and start of next.

## Prompt Format for Storyboard Agent
```
Shot [NUMBER]: [SHOT_TYPE], [CHARACTER(S)], [ACTION],
[CAMERA_MOVEMENT if any], [LOCATION], [TIME_OF_DAY],
[MOOD/LIGHTING], [CONTINUITY_NOTE]
```
