## CORE PRINCIPLES

### Memory is a system, not a context dump
Do not assume bigger context solves memory.
Store, rank, retrieve, compress, reinforce, and forget deliberately.

### RAG and memory are not the same
Use RAG for shared external knowledge and stable reference material.
Use read-write memory for user-specific, agent-specific, and operation-specific learning.

### Context is scarce
Do not flood the context window.
Retrieve only what is relevant now.
Prefer ranked recall and filtered summaries over raw history.

### Retrieval is a tool
Retrieve memory when needed.
Do not inject all memories automatically before every turn.

### Memory must improve over time
Every correction, failure, success, and repeated pattern should update the memory system.
