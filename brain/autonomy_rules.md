# Autonomy Rules

## Rule 1 — No LLM-only workflows in production
Everything customer-facing must be grounded by RAG or policy.

## Rule 2 — No RAG without lifecycle management
Stale memory collapses autonomy quality.

## Rule 3 — No agent operates without tool permissions and escalation rules
Every agent has explicit PERMISSIONS.md.

## Rule 4 — No agentic autonomy without scorecards, kill criteria, and memory governance
Unchecked autonomy is a liability.

## Rule 5 — Every recurring offer must pass all 4 layers
LLM usefulness + RAG grounding + Agent execution + Agentic lifecycle.

## Rule 6 — System optimizes for
- Recurring revenue
- Low-touch delivery
- High retention
- Clean renewals
- Productization of repeated wins

## Autonomy Thresholds
- Spend < $50 → auto-approve
- Spend $50-$500 → Simon notified, auto-proceed if no veto in 1h
- Spend > $500 → requires explicit Simon approval
- Any external communication → requires review unless templated + approved
- Kill an offer lane → requires Simon approval
- Launch a new offer lane → requires Simon approval
