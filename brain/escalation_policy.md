# Escalation Policy

## Severity Levels

### P0 — Critical
Revenue loss, data breach, client-facing failure, system down.
→ Immediate alert to Simon. All agents pause affected workflows.

### P1 — High
Missed SLA, failed delivery, billing error, compliance gap.
→ Alert Simon within 15 min. Tom reviews. Affected agent holds.

### P2 — Medium
Offer underperforming, memory quality degrading, cost overrun.
→ Log in reports. Alex reviews on next cycle. No immediate escalation.

### P3 — Low
Optimization opportunity, minor improvement, nice-to-have.
→ Log in backlog. Forecaster reviews weekly.

## Escalation Channels
1. Telegram (primary) — direct message to Simon
2. Memory log — always log regardless of channel

## Who Can Escalate
Any agent can escalate. Tom has veto power on any agent action.
Alex prioritizes escalations and allocates response resources.
