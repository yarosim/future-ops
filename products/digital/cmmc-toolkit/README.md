# CMMC 2.0 Readiness Toolkit

Complete self-assessment kit for defense suppliers pursuing CMMC Level 2 / NIST 800-171.

## What's inside
- `checklist.md` — all 110 NIST 800-171 Rev 2 controls (14 families), plain-English requirement, small-supplier guidance, evidence to collect, common gaps.
- `gap-tracker.csv` — 110-row tracker: status, owner, evidence location, priority, SPRS impact.
- `sprs-guide.md` — how DoD SPRS 110-point scoring works, worked example, how to improve.

## Run a self-assessment in 5 steps
1. Open `gap-tracker.csv`, assign an Owner per control.
2. Work family by family through `checklist.md`; mark Met/Partial/Not Met.
3. For each NOT MET, note the evidence gap and a target date in the CSV.
4. Score yourself against `sprs-guide.md` for an SPRS estimate.
5. Build your POAM from the Not Met rows; start with Access Control + System & Comms Protection.

## Disclaimer
Self-assessment aid — not a substitute for a formal C3PAO assessment or legal advice. Verify against the current NIST SP 800-171 Rev 3 / CMMC 2.0 rules before submitting to a C3PAO.
