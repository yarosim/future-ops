# Annual HIPAA Audit Checklist — Small Practice

**Practice:** [PRACTICE NAME] | **Auditor:** [NAME] | **Date:** [DATE] | **Year:** [YEAR]

Rate each item: ✅ In place · ⚠️ Partial/gap · ❌ Missing · N/A. Attach evidence (documents, screenshots, logs) for each ✅.

## A. Governance & Documentation

- [ ] Privacy Officer designated in writing (§164.530(a))
- [ ] Security Officer designated in writing (§164.308(a)(2))
- [ ] All 18 policies reviewed and updated within the last 12 months
- [ ] Policy review dates and sign-offs documented
- [ ] Notice of Privacy Practices current, distributed, and acknowledgments retained
- [ ] NPP posted on website (if applicable) and available on request
- [ ] Documentation retained 6 years (§164.530(j))

## B. Risk Analysis & Management

- [ ] Annual risk analysis completed for current year (§164.308(a)(1)(ii)(A))
- [ ] Asset inventory of all ePHI systems is current
- [ ] Remediation plan from last analysis updated — all items closed or on schedule
- [ ] Risk analysis performed after major system changes this year

## C. Workforce

- [ ] All staff completed HIPAA training within X days of hire (§164.530(b))
- [ ] Annual refresher training completed by all staff
- [ ] Training completion records on file
- [ ] Confidentiality agreements/acknowledgments signed by all workforce members
- [ ] Sanctions applied and documented for any violations this year
- [ ] Terminated employees' access disabled within 24 hours (check against roster)

## D. Access & Accounts

- [ ] Every user has a unique ID; no shared logins
- [ ] Access matches current roles (semi-annual access review done)
- [ ] MFA enabled on EHR, email, and remote access
- [ ] Automatic screen lock configured (10–15 min)
- [ ] Password policy enforced (length, complexity, no reuse)

## E. Technical Security

- [ ] Full-disk encryption on all laptops/tablets/phones storing ePHI
- [ ] Email encryption in transit (TLS 1.2+) verified
- [ ] Antivirus/EDR active and updated on all endpoints
- [ ] OS and application patching current
- [ ] No end-of-life operating systems in use
- [ ] Firewall/router configuration reviewed; Wi-Fi uses WPA2/3 with separate guest network
- [ ] Audit logs enabled on EHR and reviewed [monthly] with documented reviews
- [ ] VPN required for remote access to ePHI
- [ ] No PHI on personal cloud storage; use of approved secure services only

## F. Business Associates

- [ ] Current vendor list of all BAs with PHI access
- [ ] Signed BAAs on file for every BA (§164.504(e)) — including IT support, shredding, billing, telehealth, backup vendors
- [ ] BA breach-notification timelines verified (≤60 days)
- [ ] Annual review of vendor list for additions/terminations

## G. Physical Security

- [ ] Facility access controls in place (locks, badges, visitor log)
- [ ] Workstations positioned to prevent screen viewing by public
- [ ] Privacy filters installed where needed
- [ ] Server/network equipment in locked area
- [ ] Paper records in locked storage
- [ ] Clean desk practice observed
- [ ] Keys/badges inventoried; terminations retrieve all credentials

## H. Devices & Media

- [ ] Asset inventory current (serial numbers, assigned users, encryption status)
- [ ] USB drives: issued, encrypted, personal drives prohibited
- [ ] Secure disposal process documented; certificates of destruction retained
- [ ] Media reuse sanitized per NIST 800-88 before redeployment
- [ ] Off-site media movement logged

## I. Backup & Contingency

- [ ] Backups run [daily] and verified
- [ ] At least one offsite and one immutable/offline copy
- [ ] Backup restoration tested [quarterly] with logged results
- [ ] Downtime procedures documented and forms stocked
- [ ] Disaster recovery contacts current; tabletop exercise done this year

## J. Incident & Breach Readiness

- [ ] Incident response policy current; team contacts current
- [ ] All incidents this year logged with documented risk assessments
- [ ] Breach notifications (if any) sent within 60 days and documented
- [ ] HHS portal submissions (if any) completed
- [ ] Encryption status documented per device (safe-harbor readiness)

## K. Patient Rights Operations

- [ ] Access requests fulfilled within 30 days; fees reasonable
- [ ] Amendment requests handled within 60 days
- [ ] Accounting-of-disclosures log maintained
- [ ] Restriction requests honored for paid-in-full services (§164.522(a)(1)(vi))
- [ ] Confidential communication requests honored
- [ ] Complaint log maintained; complaints resolved within target
- [ ] No retaliation documented or alleged

## L. Communications

- [ ] Email policy followed; no auto-forwarding to personal accounts
- [ ] Patient email consent documented
- [ ] Fax cover sheets and number verification in practice
- [ ] Voicemail messages minimal
- [ ] No PHI on social media; review responses compliant

## M. Overall

- [ ] Findings summary written with priorities and owners
- [ ] Remediation items assigned with due dates
- [ ] Audit results presented to practice owner/leadership
